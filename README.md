# Wonderwake06 — Openpaper 0.5.0

A larger Colorwake drawing studio for Wonderwake, the independent Black Flag learning ship. Start with START_HERE.txt for the existing GitHub Pages upload workflow.

The paper fills the available studio. A compact dock opens animated colour and pen trays over the paper. Pen, pencil, marker and eraser; twelve colours; four thicknesses; undo/redo; Save and Gallery in the fixed header. Finger drawing and the existing Pencil guard remain available. PNG downloads, new paper and shapes are under More.

Each painting can contain up to 2,000 strokes / 50,000 sampled points. Galleries still hold 12 pictures for each learner. Existing learners, pictures, learning progress and exports remain readable. A painting records its paper shape so rotating the device fits the original without stretching the drawing. New pictures use the available aspect ratio when opened.

Saved pictures and progress remain on this device, in Wonderwake's existing IndexedDB database. This is a family preview with local learner choices, not cloud backup or protected child accounts. The Engine, orders and fleet permissions are separate and unchanged.

Release details: CHANGELOG.md. Test evidence and device limitations: VERIFY.txt. Historical Colorwake learning behaviour: COLORWAKE.md. Learner workflow: LEARNERS.md. Fleet passport: WONDERWAKE_VESSEL.json. Synthetic automated tests: verification/.

Before uploading, keep a progress export for each learner you want backed up. Do not clear website data. recovery/ contains the previous application ZIP, not learner records. New Openpaper drawings need Openpaper or later; older builds cannot read all new gallery data.
